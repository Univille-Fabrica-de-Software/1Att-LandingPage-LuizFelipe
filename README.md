## Descrição

Landing page acadêmica desenvolvida a partir da pesquisa "Estudo Comparativo de Vagas de Desenvolvimento em Joinville e no Mercado Nacional".
O projeto apresenta um panorama comparativo entre vagas de tecnologia locais, em Joinville/SC, e vagas nacionais na modalidade remota, com base em oito anúncios publicados no LinkedIn, com base na data 05/08/2026.

## Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 5.3.8
* Git
* GitHub
* GitHub Pages

## Recursos utilizados no projeto

* HTML semântico com `header`, `main`, `section` e `footer`;
* Menu de navegação responsivo utilizando Bootstrap;
* Sistema de grid do Bootstrap;
* Cards para apresentação das vagas e informações da pesquisa;
* CSS para personalização da página;
* Responsividade para diferentes tamanhos de tela;
* Efeitos de `hover` nos cards e botões;
* JavaScript do Bootstrap para funcionamento do menu responsivo.

## Seções da página

A landing page foi organizada nas seguintes seções:

* **Início:** apresenta o título do projeto, uma breve descrição da pesquisa e o botão para explorar as vagas.
* **Pesquisa:** apresenta o objetivo e o contexto do levantamento realizado.
* **Vagas:** apresenta as oportunidades analisadas, separando o mercado local do mercado nacional.
* **Tecnologias:** apresenta as principais tecnologias encontradas nas vagas analisadas.
* **Competências:** apresenta competências técnicas e comportamentais identificadas durante a pesquisa.
* **Análise:** apresenta as principais conclusões obtidas a partir da comparação das vagas.
